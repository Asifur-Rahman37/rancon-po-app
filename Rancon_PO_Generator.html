🔗 Shared Data (Multi-Computer)

Let multiple computers see the same POs, requisitions, suppliers, products, and user accounts — either via a local office server (recommended: works in any browser, no manual reconnecting), or a shared file on a network drive (Chrome/Edge only, needs occasional reconnecting).

Local Server (recommended)

If you opened this app via a web address (like http://192.168.1.23:3000), it's already connected automatically — no setup needed here. If you opened the file directly and a teammate already has the server running, enter its address below to join.

Or: Shared File (Chrome/Edge only)

A shared JSON file on a network drive or synced folder. Not real-time — new records merge in automatically (~every 20 seconds), but editing the exact same record within the same few seconds means the last save wins.

Backup your data

All your POs, suppliers and delivery locations are stored in this browser only (on this PC), unless connected to shared data above. Export a backup file regularly, especially before clearing browser data or switching computers.

Restore from backup

Restoring merges with — and can overwrite — your current saved POs with matching PO numbers.
